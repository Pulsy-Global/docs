**Released November 5, 2026**

This release adds five bridges and the Near chain to the tracked coverage, adds an endpoint that lists the bridge contract addresses behind tracked transfers, and tags THORChain and Chainflip transfers that only partly completed.

## Expanded coverage

- Near is now a supported chain, with [Near Intents](https://near-intents.org) tracked to and from Near.
- [Hyperliquid](https://hyperliquid.xyz) is now tracked.
- [Hyper Unit](https://hyperunit.xyz) is now tracked.
- [Skip](https://go.skip.build) is now tracked.
- [USDT0](https://usdt0.to) is now tracked.
- [Bitget Wallet](https://web3.bitget.com/en/swap) is tracked to and from Solana again.

The full list of tracked bridges lives on the [Supported Bridges](/xflow/supported-bridges/overview) page and on the [XFlow home page](https://xflow.pulsy.app).

## API changes

A new endpoint lists the bridge contract addresses behind the transfers we track. For each address it shows:

- The chain.
- The direction.
- When it was first seen and when it was last seen.
- How many transfers went through it.
- How much volume went through it.

The full shape is on the [Get Bridge Addresses](/xflow/api-reference/endpoints/get_bridge_addresses) page.

THORChain and Chainflip transfers that only partly completed now carry a `partial-execution` tag. Its value says what happened:

- `refund`: part of the funds was sent back. THORChain and Chainflip.
- `split`: the output arrived in more than one part. THORChain only.

Their `usdMismatchStatus` is now `OK` instead of `MismatchDetected`. How the status is worked out is on the [USD Mismatches](/xflow/getting-started/in-out-usd-mismatch) page.
